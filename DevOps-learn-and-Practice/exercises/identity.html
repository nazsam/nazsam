Identity & Zero Trust

What are the three core principles of Zero Trust?

Answer

1. Verify explicitly — authenticate and authorize every request. 2. Least privilege access — just-in-time, just-enough. 3. Assume breach — segment, monitor, limit blast radius.

What is phishing-resistant MFA?

Answer

MFA resistant to credential phishing — FIDO2/WebAuthn security keys or passkeys. SMS and push-only MFA are weaker against AiTM (adversary-in-the-middle) attacks.

What is Conditional Access?

Answer

Policy engine (Microsoft Entra and similar) that grants/denies/requires step-up auth based on user, device, location, risk score, and app sensitivity — core Zero Trust enforcement.

Explain the difference between authentication and authorization.

Answer

Authentication = proving identity (who). Authorization = determining permitted actions (what). AuthN without AuthZ still allows over-privileged access.

What is Privileged Identity Management (PIM)?

Answer

Just-in-time elevation to admin roles with approval, time bounds, and audit — reduces standing privileged access, a top attacker target.

What is legacy authentication and why block it?

Answer

Protocols that don't support MFA (basic auth, some IMAP/POP/SMTP). Attackers bypass MFA via these paths — disable at tenant level where possible.

What is an impossible-travel alert?

Answer

Detection of two successful sign-ins from geographically distant locations in a physically implausible time window — possible credential compromise or token theft.

How does OAuth differ from SAML in enterprise SSO?

Answer

SAML = XML-based, common for browser SSO to SaaS. OAuth 2.0 / OIDC = token-based, dominant for modern APIs and mobile/SPA. Many enterprises use both.

What is a service principal vs a managed identity?

Answer

Both are non-human identities. Managed identity is platform-managed (no credential rotation burden). Service principal is app registration you manage — common for CI/CD and third-party integrations.

What signals would you use for risk-based authentication?

Answer

Impossible travel, unfamiliar device, anonymous IP/Tor, password spray patterns, impossible token use, sign-in from atypical country, and recent credential leak exposure.
