Detection & SOC

What is the MITRE ATT&CK framework used for?

Answer

A knowledge base of adversary tactics and techniques — used to map detections, gap analysis, purple teaming, and reporting in consistent language.

What makes a detection rule "high fidelity"?

Answer

Low false-positive rate in your environment, clear investigative context, mapped to ATT&CK, and actionable response steps — not just regex on noisy events.

Explain the difference between SIEM and XDR.

Answer

SIEM aggregates logs, correlates, alerts — often multi-vendor. XDR integrates endpoint, email, identity, cloud telemetry natively for cross-domain detection and response — tighter product integration.

What is detection engineering?

Answer

Disciplined creation, testing, tuning, and lifecycle management of detection content — treating rules as code with version control, peer review, and metrics (precision, coverage).

What is a purple team exercise?

Answer

Collaborative red+blue activity — attackers simulate TTPs while defenders validate detections and response in real time. Improves coverage without full adversarial surprise of red team-only.

Name three common data sources for cloud identity detections.

Answer

Entra ID / Okta sign-in logs, CloudTrail / Azure Activity Log, Defender for Identity, CASB logs, and MFA/Conditional Access failure events.

What is a Sigma rule?

Answer

Vendor-agnostic detection format in YAML — write once, convert to Splunk, Sentinel KQL, Elastic, etc. Promotes portable detection content.

How do you measure SOC effectiveness beyond alert volume?

Answer

MTTD, MTTR, false-positive rate, detection coverage vs ATT&CK, % alerts with documented runbooks, and mean time to containment for simulated incidents.

What is SOAR and when is it valuable?

Answer

Security Orchestration, Automation, and Response — automates repetitive enrichment, ticketing, containment. Valuable after mature detections; dangerous if automating immature playbooks.

What is log tampering and how do you defend against it?

Answer

Attackers delete or modify logs to hide activity. Defend with immutable storage (WORM, S3 Object Lock), centralized forwarding, separate admin accounts for log platforms, and cross-region replication.
