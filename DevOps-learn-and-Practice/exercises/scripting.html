Scripting & Automation

Why automate security response playbooks?

Answer

Consistency, speed at scale, reduced analyst toil — but only after the procedure is validated manually; bad automation amplifies mistakes.

What is Infrastructure as Code (IaC)?

Answer

Defining infrastructure in versioned files (Terraform, Bicep, CloudFormation) — enables review, testing, drift detection, and repeatable secure baselines.

How would you scan Terraform before apply?

Answer

tfsec, checkov, or Trivy config in CI — block public S3, open SGs, missing encryption. See secure-terraform-aws.

What is idempotency and why does it matter for security scripts?

Answer

Running a script twice produces the same secure state — safe for remediation at scale without unintended side effects.

Name a safe pattern for storing API keys in automation.

Answer

Secret manager (Vault, AWS Secrets Manager, GitHub Actions secrets) + short-lived tokens via OIDC — never commit plaintext keys.

What is a runbook vs a playbook?

Answer

Often used interchangeably; runbook = step-by-step ops procedure. Playbook in SOC context may include decision branches and automation hooks (SOAR).

How do you test a detection script before production?

Answer

Unit tests with sample logs, purple-team validation, shadow mode (alert without block), measure false positives over a baseline period.

What is GitOps drift detection?

Answer

Compare live cluster/cloud state to Git-declared desired state — alert or auto-reconcile when someone changes production manually.

Why use structured logging in security automation?

Answer

Machine-parseable fields (JSON) enable reliable alerting, correlation, and SOAR enrichment — grep on unstructured logs doesn't scale.

What language is common for security glue code?

Answer

Python (libraries, APIs), PowerShell (Microsoft ecosystem), Go (CLI tools, operators). Pick what matches your stack and hiring pool.
