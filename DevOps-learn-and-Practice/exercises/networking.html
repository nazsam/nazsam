Networking & TLS

What problem does TLS solve?

Answer

Confidentiality, integrity, and server authentication on untrusted networks — prevents passive eavesdropping and many MITM attacks when properly validated.

What is certificate pinning?

Answer

Hard-coding expected cert/public key — prevents trust in rogue CAs. Useful for mobile/high-security; careful with rotation complexity.

Explain DNS over HTTPS (DoH) security trade-offs.

Answer

Encrypts DNS queries from local network observers — but concentrates trust in the DoH provider. Enterprise may require split-horizon DNS policies.

What is a VPC security group vs NACL?

Answer

Security group = stateful, instance-level firewall (AWS). NACL = stateless subnet-level filter. Defense in depth uses both.

What ports would you expect for a hardened web app?

Answer

443 (HTTPS) public; admin/DB not public — internal only or via bastion/zero-trust access. Block 22/3389 from 0.0.0.0/0.

What is mTLS?

Answer

Mutual TLS — client and server both present certificates. Common in service meshes and Zero Trust service-to-service auth.

What is split horizon DNS?

Answer

Different DNS answers inside vs outside the corporate network — internal hosts resolve private IPs; external users get public endpoints only.

How does a WAF differ from a network firewall?

Answer

WAF inspects HTTP/L7 for OWASP-style attacks (SQLi, XSS). Network firewall filters IPs/ports/L4. Both layers complement each other.

What is HSTS?

Answer

HTTP Strict Transport Security header — browsers refuse HTTP downgrade for the domain, mitigating SSL-stripping attacks.

Why monitor east-west traffic in a data center?

Answer

Lateral movement after initial compromise — attackers pivot server-to-server. Micro-segmentation and NDR detect anomalous internal flows.
