Kubernetes Security

What is Pod Security Admission (PSA) and how does it differ from PodSecurityPolicy?

Answer

PSA is built-in (K8s 1.25+) enforcement via namespace labels (privileged, baseline, restricted). PodSecurityPolicy was deprecated — PSA is simpler, namespace-scoped, and actively maintained.

Why is runAsNonRoot important in a pod securityContext?

Answer

Running as non-root limits container breakout impact — an attacker exploiting the app often cannot install packages, bind privileged ports, or modify host-mounted paths as easily.

What does a default-deny NetworkPolicy accomplish?

Answer

Blocks all ingress and egress unless explicitly allowed — implementing zero-trust networking inside the cluster. Most clusters ship open by default; default-deny is a critical hardening step.

What is the principle of least privilege for Kubernetes RBAC?

Answer

Grant Roles or ClusterRoles with the minimum verbs/resources needed — prefer namespace-scoped Roles + RoleBindings over cluster-admin. Audit with kubectl auth can-i.

Name three common Kubernetes misconfigurations that lead to compromise.

Answer

1. Overly permissive RBAC / cluster-admin bindings. 2. Exposed secrets in ConfigMaps or env vars. 3. Missing network policies (lateral movement). Also: privileged containers, hostPath mounts, latest tags without image verification.

What is an admission controller and give two security use cases.

Answer

Webhook or built-in gate that mutates or validates resources before persistence. Use cases: Kyverno/OPA block non-compliant pods; image signature verification reject unsigned images.

How does Falco differ from kube-bench?

Answer

Falco = runtime behavioral detection (syscalls, K8s audit events). kube-bench = configuration benchmark against CIS Kubernetes checks. Complementary, not interchangeable.

What is a ServiceAccount and why should workloads use dedicated ones?

Answer

Identity for pods calling the K8s API. Dedicated ServiceAccounts per workload enable scoped RBAC — a compromised frontend pod shouldn't inherit backend cluster permissions.

Explain the risk of mounting the Docker socket into a pod.

Answer

Full host container control — equivalent to root on the node. Never mount /var/run/docker.sock in production workloads unless absolutely required and heavily restricted.

What is seccomp and AppArmor in the K8s context?

Answer

Linux mandatory access controls limiting syscalls (seccomp) and file/network capabilities (AppArmor/SELinux). K8s exposes them via securityContext to shrink attack surface.
