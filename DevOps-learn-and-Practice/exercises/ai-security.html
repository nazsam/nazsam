AI & LLM Security

Name three items from the OWASP Top 10 for LLM Applications.

Answer

Examples: Prompt Injection, Insecure Output Handling, Training Data Poisoning, Model Denial of Service, Supply Chain Vulnerabilities, Sensitive Information Disclosure.

What is prompt injection?

Answer

Manipulating an LLM via crafted input to override instructions, leak data, or trigger unintended actions — direct (user input) or indirect (poisoned retrieved content).

How does the A2A (Agent2Agent) protocol relate to MCP?

Answer

MCP connects agents to tools/data. A2A (Agent2Agent Protocol) enables agent-to-agent collaboration — discovery via Agent Cards, standardized JSON-RPC tasks. Complementary layers.

What is the NIST AI RMF?

Answer

AI Risk Management Framework — Govern, Map, Measure, Manage functions for trustworthy AI. Voluntary guidance for identifying and mitigating AI-specific risks.

Why should LLM outputs be treated as untrusted input?

Answer

Models can hallucinate, leak training data, or emit executable content — sanitize and validate before rendering HTML, running SQL, or passing to downstream systems (Insecure Output Handling).

What is model inversion and membership inference?

Answer

Attacks infer training data or whether a record was in training — privacy risks for sensitive datasets. Mitigate with differential privacy, minimization, and access controls.

What guardrails should wrap a production LLM API?

Answer

Input filtering, output schema validation, rate limits, authN/Z, logging without secrets, human review for high-risk actions, and grounding with cited retrieval sources.

What is MITRE ATLAS?

Answer

Adversarial ML knowledge base — tactics/techniques for attacking and defending ML systems, analogous to ATT&CK for traditional IT.

When should AI assist vs decide in security workflows?

Answer

AI assists investigation, drafting, correlation — humans decide on containment, access revocation, and regulatory notification. See 2025-ai-threat-modeling.

What data should never be pasted into a public LLM?

Answer

Production credentials, PII/PHI, unreleased vuln details, classified material, full production logs with tokens, and proprietary customer data.
