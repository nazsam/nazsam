Cloud Security

What is CSPM?

Answer

Cloud Security Posture Management — continuous assessment of cloud configs against benchmarks (CIS, NIST) to find public storage, open SGs, missing encryption, excessive IAM, etc.

Explain the shared responsibility model for IaaS vs SaaS.

Answer

IaaS: provider secures physical/network/hypervisor; customer secures OS, apps, data, IAM. SaaS: provider secures app/platform; customer secures identity, data classification, access policies. Always know your line.

What is a wildcard IAM policy and why is it dangerous?

Answer

"Action": "*", "Resource": "*" grants unrestricted API access. One compromised key = full account takeover. Replace with scoped actions and resource ARNs.

How does encryption at rest differ from in transit in cloud storage?

Answer

At rest: data encrypted on disk/object store (SSE-S3, SSE-KMS, Azure SSE). In transit: TLS between client and service. Both required; neither replaces the other.

What is a landing zone in cloud architecture?

Answer

A pre-configured, secure multi-account/subscription foundation — logging, guardrails, networking hub, IAM baseline — before application teams deploy workloads.

Name three AWS services commonly used for security monitoring.

Answer

CloudTrail (API audit), GuardDuty (threat detection), Security Hub (posture aggregation). Also Config, Macie, Inspector depending on use case.

What is Azure Policy vs Azure RBAC?

Answer

RBAC = who can take actions. Policy = what configurations are allowed (e.g., deny public IPs on storage). Use both — RBAC without policy still allows insecure configs.

What is the blast radius of a compromised cloud admin account?

Answer

Potentially entire tenant — data exfiltration, resource deletion, persistence via new IAM users, crypto-mining. Mitigate with PIM/PAM, MFA, break-glass procedures, and activity alerting.

What is infrastructure drift and why does it matter for security?

Answer

Manual console changes diverging from IaC — untracked open ports, disabled logging. Drift breaks compliance and incident reconstruction. Detect with Config/Terraform drift scans.

How would you secure an S3 bucket storing sensitive logs?

Answer

Block public access, enforce SSE-KMS, least-privilege bucket policy, access logging, Object Lock for immutability, VPC endpoints for private access, and lifecycle rules.
