📖 What this is

A structured, honest roadmap I'm working through in public. Every box below is either done ✅

or in progress. Where a stage produced something real, I link the repo that proves it. It doubles

as a study path anyone can follow — everything referenced is free.

Principle: breadth of awareness, depth in one lane. Go deep on DevSecOps + Cloud Security

first; keep AI-security as a lighter parallel track. Ship small, ship often, learn out loud.

> 📊 See also: Learn cybersecurity free · curated resources · project ideas per stage
