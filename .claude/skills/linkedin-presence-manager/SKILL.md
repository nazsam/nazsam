# LinkedIn Presence Manager

A local-first Claude skill for managing LinkedIn content, engagement, profile optimization, inbox triage, content audits, and text humanization.

## Commands

### /linkedin-post
Create LinkedIn post drafts using proven hook formulas.

### /linkedin-comment
Generate thoughtful comments for LinkedIn posts.

### /linkedin-reply
Draft replies to comments and conversations.

### /linkedin-profile-score
Score a LinkedIn profile across key areas.

### /linkedin-profile-improve
Suggest improvements for headline, about section, experience, and skills.

### /linkedin-week-plan
Generate a 7-day content plan.

### /linkedin-engagement-plan
Create a daily engagement strategy.

### /linkedin-repurpose
Convert one piece of content into multiple formats.

### /linkedin-dm-sequence
Build networking and outreach message sequences.

### /linkedin-inbox-triage
Categorize inbox messages and suggest responses.

### /linkedin-audit
Review past content and identify improvement opportunities.

### /humanize-text
Clean AI-generated text by:
- Removing common AI phrases
- Removing invisible Unicode characters
- Normalizing punctuation
- Improving readability
- Providing human-likeness scores before and after

## Safety Rules

- Never publish content automatically.
- Never use LinkedIn APIs.
- Draft text only.
- Always require user review before posting.
